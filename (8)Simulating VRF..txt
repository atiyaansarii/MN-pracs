hostname R1

ip ospf 1 area 0
int f0/0
ip add 10.0.0.1 255.255.255.0
no shut
ip ospf 1 area 0

R2 :
hostname R2

no shut
ip ospf 1 area 0
int f0/1
ip add 10.0.1.2 255.255.255.0
no shut

R3 :
hostname R3

R1
int f0/1
no shut
ip add 192.168.1.1 255.255.255.0

Now at this point we have R4 peering to R1 but in the global routing table of R1 which is not what we 
want 
For this mpls tutorial I will be using VRF RED 

Router R1:
ip vrd RED
rd 4:4
router-target both 4:4


So now we have configured the VRF on R1 we need to move the interface F1/0 into that VRF
 
Router R1: 
int f0/1
ip vrf forwarding RED

Now notice what happens when you do that – the IP address is removed. 
You just need to re-apply it. 

Router R1: 
int f0/1
ip address 192.168.1.1 255.255.255.0

Now if we view the config on R1 int f1/0 you can see the VRF configured. 

R1#sh run int f1/0
R1#sh ip route 
R1#sh ip route vrf RED 

We just need to enable OSPF on this interface and get the loopback address for R4 in the VRF RED 
routing table before proceeding. 
 
Router R1: 
int f0/1
ip ospf 2 area 2
R1#sh ip route vrf RED 

Router 5 will peer OSPF using process number 2 to a VRF configured on R3. It will use the local site 
addressing of 192.168.2.0/24. 

Router R5: 
int lo0 
ip add 5.5.5.5 255.255.255.255 
ip ospf 2 area 2 
int f0/0 
ip add 192.168.2.6 255.255.255.0 
ip ospf 2 area 2 no shut

Router R3: 
int f1/0 
no shut 
ip add 192.168.2.3 255.255.255.0 

Router R3: 
ip vrf RED 
rd 4:4 
route-target both 4:4

Roouter R3: 
int f1/0 
ip vrf forwarding RED 
int f1/0 
ip address 192.168.2.1 255.255.255.0 
R3#sh run int f1/0 
int f1/0 
ip ospf 2 area 2

Check the routes in vrf RED 
R3#sh ip route vrf RED 

Check the routes on R4 
R4#sh ip route 

When we are done we want to see 5.5.5.5 in there so we can ping across the MPLS 
Check the routes on R1 
R1#sh ip route
R1#sh ip route vrf RED 


Redistribute OSPF into MP-BGP on R1 
Router R1: 
router bgp 1 
address-family ipv4 vrf RED 
redistribute ospf 2

 
Redistribute OSPF into MP-BGP on R3 
Router R3: 
router bgp 1 
address-family ipv4 vrf RED 
redistribute ospf 2
